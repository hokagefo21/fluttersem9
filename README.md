# SRS 9 — иконка и тестирование Post Explorer

Задание выполнено после SRS 8 в том же приложении. Исходная версия SRS 8 отмечена Git-тегом srs-8. Инструкция модуля постов: README-SRS8.md. Регистрация Firebase из лабораторной 7 также сохранена.

## Собственная иконка
assets/icon/app_icon.png — 1024 × 1024, собственный знак: карточка поста и лупа с отметкой проверки. SVG-исходник расположен рядом. Генерация настроена в pubspec.yaml через flutter_launcher_icons. Созданы обычные и адаптивные Android-иконки, а также набор iOS. На Windows проверяется запуск Android; iOS здесь не запускался.
Повторная генерация: flutter pub run flutter_launcher_icons.

## Unit Tests
В test/post_validation_test.dart — 7 тестов функции валидации реальной формы создания поста: пустой, короткий, корректный и длинный заголовок; короткий, корректный и длинный текст.
Ещё 11 модульных тестов SRS 8 находятся в test/posts_test.dart: модели, Repository, mock HTTP, фильтрация, пагинация, кэш, POST и устаревшие ответы.

## Widget Tests
В test/post_widgets_test.dart — 4 проверки интерфейса приложения:
1. Заголовок Post Explorer, поле поиска и действие создания.
2. Изменение интерфейса после ввода поискового запроса без совпадений.
3. Переход из списка к деталям, отображение комментариев и возврат назад.
4. Валидация формы до отправки POST (число запросов не увеличивается).
Три теста регистрации лабораторной 7 сохранены в test/widget_test.dart.

Итого: 25 тестов пройдены. Команда flutter test. Полный вывод: docs/srs9-tests.txt. flutter analyze: No issues found. APK собирается успешно.

## Ответы на контрольные вопросы
1. Launcher Icon — значок приложения в списке приложений и на домашнем экране.
2. flutter_launcher_icons создаёт наборы значков нужных размеров для платформ.
3. Генерация задаётся в pubspec.yaml в разделе flutter_launcher_icons.
4. Unit Test проверяет отдельную функцию или класс, например PostValidation.
5. Unit Test проверяет логику, Widget Test — построение UI и взаимодействия.
6. expect сравнивает фактическое значение с ожидаемым matcher.
7. test объявляет самостоятельную проверку и её название.
8. testWidgets создаёт тест с WidgetTester для построения экрана, нажатий и проверки дерева виджетов.
9. flutter test запускает автоматические тесты проекта и возвращает ненулевой код при ошибках.
10. Тестирование до публикации помогает находить ошибки логики, навигации, ввода и сетевых сценариев до того, как их встретят пользователи.
